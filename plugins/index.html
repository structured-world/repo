Add the marketplace once

With Codex CLI installed, run this command on the computer where you use Codex. It adds the plugin catalog; it does not install or authorize a plugin.

codex plugin marketplace add structured-world/repo --sparse .agents/plugins
  1. Choose a plugin above and select Install in Codex.
  2. Review and confirm installation in Codex.
  3. Open the plugin's settings to connect your service. Enter secrets in its private setup panel.

Installation buttons require this marketplace to be registered. If Codex cannot find it, it opens the Plugins page. Desktop plugins run locally; GitLab MCP requires Node.js 24+.

To refresh the catalog, run codex plugin marketplace upgrade sw-foundation. Review available plugin updates in Codex.
